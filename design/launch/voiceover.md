# Island launch film: voice-over

The film is 27.3 seconds. Every line below has a fixed moment, taken from the reference film, so the
voice, the pictures and the music land together.

## Paste this into ElevenLabs

Generate it as **one take** (the pauses are written in), or line by line if a line needs a retake.
Either way is fine: the lines get placed on the timeline one by one afterwards.

```
We've all missed this question before.

But...

what if one glance... told you everything?

Island.

No more endless alt-tabbing.

No more forgotten agents.

One click, and done.

Agents. Answers. Tabs. Limits. Pure focus.

All in one glance.

Island.
```

## Settings that fit this film

- **Voice:** a calm, warm, confident narrator, mid-to-low pitch, the "product film" kind. Not an announcer,
  not excited. (In the voice library, search for: calm, narration, documentary, warm.)
- **Model:** Eleven v3 or Multilingual v2.
- **Stability:** about 45-55. **Similarity:** 75. **Style:** 15-25. **Speed:** 0.95-1.0.
- If "alt-tabbing" comes out wrong, type it as `alt tabbing`.
- The two "Island." lines should sound different: the first one warm and certain, the second one slower,
  with weight (it is the last word of the film). Generate that word a few times and keep the best two.
