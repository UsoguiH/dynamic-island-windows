# Code of Conduct

Island is a small project and we want it to stay a friendly one.

**Do**
- Be kind and patient, especially with people who are new to the code or to open source.
- Talk about the work: the code, the motion, the idea. Not about the person.
- Assume good intent, and say so when something reads badly to you.

**Don't**
- Insult, harass or mock anyone, in issues, pull requests or anywhere else connected to the project.
- Post someone's private information.
- Keep pushing after you've been asked to stop.

If someone breaks these rules, a maintainer may edit or remove their comments, close their issues or block them from the repository.

To report a problem, contact the maintainer through GitHub ([UsoguiH](https://github.com/UsoguiH)), or use GitHub's own **Report content** button on the comment. Reports are kept private.

This is a short version of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which applies in full where this page is silent.
